# 本机多账号池工作台设计（用户已确认）

2026-10-18。以 Panel v1.13.0 为底座；视觉参考 VPS 20261015b。保留原始源码和现有服务；只在此独立目录工作，不提交、不部署。

## 必须满足
- 回环监听（127.0.0.1 / ::1），聊天不使用 API key；管理页和管理接口密码会话保护，默认 123456，可改密和离线重置；Host/Origin/CSRF 防护。
- VPS 账号独立代理与出口矩阵，失败不能回退直连；凭证导入导出；模型目录控制。
- 模块化前端，深色青绿控制台；保留任务/统计/模型/账号已有能力。
- 核心业务不依赖具体日志归档实现；空实现正常运行；用量统计独立。
- 任务业务不归属于 panel；拆分大 handler 职责。
- 保留成本感知账号池和模型级积分保底；明确域路由；会话粘性不越过账号健康检查。
- Responses 兼容，多轮记忆可选持久化，TTL/LRU/字节预算；明确适配流式的限制，不宣传原生实时流。
- 请求体/并发/历史/后台任务资源有界，不强迫无限内存或激进 GC。

## 交付与验证
隔离目录、测试、Windows 构建、本机 HTTP/浏览器验收；不使用真实账号、不调用付费上游、不自动迁入凭证。原有源码不删改。后台进程收尾停止。
