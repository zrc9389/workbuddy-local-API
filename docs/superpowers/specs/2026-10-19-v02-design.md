# v0.2 · confirmed product design

User confirmed 2026-10-19. Keep existing local-only password boundary and released v0.1 packages. No commits/deploy/real credentials/paid upstream tests without budget.

## Product
Overview is first and intentionally blank. No search/filter controls in any view; pagination is retained for bounded DOM. Account cards only enable/disable, delete, egress badge. Manual disable red; system cooldown/balance-protection yellow; normal green; terracotta primary (4 accent colors total), neutral surfaces, light/dark glass, reduced-motion.
Account low balance threshold defaults100, known balance below threshold blocks whole account; unknown balance not zero; recovery never clears manual disable. Four maintenance jobs only via one Run All entry; independent automatic activity/growth schedules off in v0.2.

## Interfaces (all /panel/api protected by existing session/CSRF)
GET overview existing + accounts[].manual_disabled, balance_blocked, balance_known, system_blocked.
POST accounts/{uid}/toggle_disabled {disabled:bool} -> {ok:true}; POST accounts/{uid}/remove existing.
POST maintenance/run {} -> {run_id,running,steps}; GET maintenance/status -> {run_id,running,steps:[{name,state,completed,failed,accounts:[{uid,state,message}]}]}. Four steps token/checkin/activity/travel. Duplicate start409.
GET meta/status; POST meta/subscriptions {url}; GET meta/nodes; POST meta/tests {}; GET meta/tests; POST meta/accounts/{uid}/bind {node}; GET meta/stats. Meta worker owns exact responses and must communicate to UI worker. Kernel/controller only loopback; credentials backend; per-account separate listener/select group, never one global selector; no TUN/system proxy. On-demand start safe shutdown only no active proxy flows. Slim metacubexd reuse adapter/assets with provenance, do not falsely claim whole upstream dashboard embedded if not.
GET/POST preferences only minimal safe fields {credit_guard_low,theme}; backend maps guard config. Other raw configuration retains developer API but no complex controls UI.

## Memory
Separate complete disk history archive from LRU cache. Memory eviction never deletes durable history. Disk/body/job limits explicit; no silent truncation; upstream context support separately verified. Intake spill only under memory pressure, bounded chunks, enqueue after complete synced write; queued request cancellation and disk full explicit. Dispatch-intent records prevent auto-replaying uncertain upstream calls. Do not claim guarantee model recall. Ordinary Chat remains caller-managed history, Responses local archive resumes.

## Demo/tests
Isolated --demo flag or demo config directory, no real credentials/network; same HTTP routes via mock upstream, dynamic logs/states. UI visibly demo. Synthetic size/token/context tests separate from real1M (requires target/tokenizer/auth/cost cap). Functional tests kernel proxy binding and task results, crash/disk full/memory cache evictions. No bulk/recursive deletion. Document incomplete items honestly.
